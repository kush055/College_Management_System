# College Management System

A comprehensive web-based application designed to streamline and automate the daily operations of a college. This system helps manage students, faculty, courses, departments, and administrative activities efficiently.

## Features

-  User Authentication and Role Management
  - Admin, Faculty, Student roles
-  Student Management
  - Add/edit/delete students
  - View student details, results, and attendance
-  Faculty Management
  - Add/edit/delete faculty members
  - Assign subjects and manage schedules
-  Course and Subject Management
  - Create and manage courses, subjects, and departments
-  Attendance
  - Mark and view attendance
-  Exam & Result Management
  - Add exams, enter marks, and generate report cards
-  Notice Board & Announcements
-  Dashboard with analytics and summaries
